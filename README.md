# ElectroStock - Inventory Management System

## Overview
ElectroStock is a full-stack MERN Inventory Management System for managing electronic products. It provides secure authentication, role-based access, dashboard analytics, and complete inventory management.

## Features
- Admin & Staff Login (JWT Authentication)
- Role-Based Access Control
- Dashboard Analytics
- Product Management (CRUD)
- Category Management
- Supplier Management
- Search & Filter
- Low Stock Monitoring
- Responsive UI

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Axios
- CSS

## Installation

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
